# LoGIC
Code for AISTATS 2026 Paper: Unified Causal Discovery and Missing Data Imputation

## Required Packages.
sortedcontainers
ordered_set
loguru
gadjid
rpy2 (to run the Multivariate Adaptive Regression Splines (MARS) that is used by GLOBE algorithm)

## Reproducibility
Original (uncommented) code that was used to run and generate experiments for the paper, alongside baseline methods and their comparisons can be found in the `./reproducibility` folder.
